# JCP submission preparation

Target journal: **The Journal of Chemical Physics (JCP)**

Recommended article type: **Article**, not Communication.

The canonical scientific sources remain:
- `paper/manuscript.tex`
- `paper/supporting_information.tex`
- `paper/references.bib`

For initial JCP submission, format these sources with the AIP Publishing REVTeX template in
`aip,jcp,preprint` mode and upload:
1. one compiled manuscript PDF;
2. one separate supplementary-material PDF.

The current AIP instructions require the manuscript order:
Title/authors/affiliations, abstract, text, conclusion, Supplementary Material section,
Acknowledgments, Author Declarations, Data Availability, references.

## Graphical abstract / highlight image

The current AIP/JCP instructions do **not** require a graphical abstract for initial submission.
AIP instead strongly recommends a **highlight image** with a revised submission.
If an article contains figures and no highlight image is supplied, AIP states that Figure 1
will be used as the highlight image.

## Author-certified items still needed

Before submission, the authors must supply:
- a Conflict of Interest statement;
- a CRediT Author Contributions statement.

These cannot be inferred safely from the scientific repository.

## Accessibility

A draft alt-text file is provided for the manuscript and supplementary tables/figures.
AIP requests alt text during revision/publication processing.

The locally compiled JCP-format review package prepared on 2026-09-27 uses REVTeX 4.2
and the AIP/JCP `preprint` option.
